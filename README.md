# Sjoerd van Kersbergen

I work on digital content and data reporting at a Dutch public organisation. On the side I build AI you can explain: a personal assistant on Notion, n8n and Claude, plus the checks that keep it honest.

## Here

**[commit-discipline](https://github.com/Kers87/commit-discipline)** - three guards for Claude Code.

- A commit names its own files, so parallel sessions never pick up each other's work.
- A file only commits after its test has demonstrably run green on exactly that content.
- In Plan Mode the AI can read and ask, and nothing else.

Each guard came out of a real incident, and each one ships with tests that prove it can fail.

## How I build

A rule gets written after something went wrong, with the incident next to it. "The tests pass" counts once it is measured.
